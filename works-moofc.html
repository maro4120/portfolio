WORKS

MOO FC（サッカークラブ）

ホームページ／自主制作（架空）

高槻にある少年サッカークラブ、という設定で作った架空のサイトです。実在の団体ではありません。

読み手は、入団を検討している保護者の方を想定しました。

「うちの子でも大丈夫か」「いつ、どこで、いくらか」を、スクロールの早い段階で判断できることを狙っています。

こんな方に近い制作です

  • 教室・スクール・クラブなど、体験や見学に来てほしい方
  • フォームより電話での問い合わせが多い業種の方
  • 写真の力で雰囲気を伝えたい方

OUTLINE 概要

種別 ホームページ（トップ＋下層ページ）
想定した目的 体験・見学の申し込みにつなげる
想定した読み手 入団を検討している保護者
使用技術 HTML / CSS / JavaScript
公開URL 架空のサイトのため公開していません

POINT 制作のポイント

  1. 1

    「うまくなるより、好きになる。」を一番大きく置いた

    競技としての強さで選ぶ方より、まず「うちの子が楽しめるか」を気にする保護者のほうが多いと考えました。

    すぐ下に「年長から中学3年生まで、男女問わず」と対象を書き、自分の子が当てはまるかを一瞬で判断できるようにしています。

  2. 2

    電話番号と申し込みボタンを、画面の上に常に置いた

    この業種は、フォームを埋めるより電話のほうが動きやすい方がいます。どちらでも動けるよう、同じ場所に並べました。

    スマートフォンでは画面の下に固定し、どこまで読んでも申し込みに戻れるようにしています。

  3. 3

    数字で規模を伝える

    創立年・在籍人数・クラス数を、最初の画面のすぐ下に並べました。

    「歴史があります」「たくさんの子が通っています」と文章で書くより、1998／128名／4クラスと並べたほうが短く伝わります。

  4. 4

    年度で変わるお知らせを、1か所にまとめた

    「2027年度 新入生 体験会 受付中」を独立した帯にしました。

    毎年書き換えが必要な部分をここだけに集めておくと、更新のときに探し回らずに済みます。
